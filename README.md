## 这是什么

Fogg Tools 是一套把福格行为模型软件化的小工具。

这个项目来自我阅读《福格行为模型》后的整理和实践。我把书中提到的行为设计思路，以及几个相关的小工具方法，提炼成可以直接在浏览器里使用的交互工具，方便大家更轻松地找到“更值得做、也更容易开始”的行为。

它适合这些场景：

- 你有一个愿望，但不知道应该先做什么。
- 你列了很多行动想法，但不知道哪个最值得开始。
- 你知道自己该做什么，却总是坚持不下来。
- 你想把一个好行为设计得更容易发生。

## 两个工具

### 黄金行为探索器

从一个愿望出发，先收集候选行为，再用“影响度”和“容易度”筛出黄金行为。

适合回答：

- 我应该先做哪个行为？
- 哪个行动最可能带来改变？
- 哪个行动既有价值，又容易开始？

### 能力链设计器

从一个困难习惯或黄金行为出发，分析执行卡点，再设计更容易发生的突破方案。

适合回答：

- 为什么这个行为总是做不到？
- 是时间、金钱、体力、脑力，还是日程安排卡住了我？
- 怎样把这个行为变得更简单、更小、更容易启动？

## 推荐用法

1. 先写下一个愿望。
2. 在黄金行为探索器里列出候选行为。
3. 找到高影响、容易做的黄金行为。
4. 把黄金行为带到能力链设计器。
5. 从技能、工具资源、行为规模等角度设计突破方案。
6. 生成一份 HTML 分析报告，作为复盘和行动记录。

你也可以直接使用其中任意一个工具。

## 如何使用

下载项目后，在本地运行：

```bash
npm install
npm run dev
```

然后打开浏览器访问：

```text
http://localhost:3000
```

如果 3000 端口被占用，可以换一个端口：

```bash
npm run dev -- -p 3001
```

这个项目也可以部署到 Vercel。

## 关于这个项目

这个项目不是对《福格行为模型》的替代，而是一个个人学习和实践后的软件化整理。希望它能帮你更快地把“我想改变”变成一个足够小、足够清楚、也足够容易开始的行动。
