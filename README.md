# Fogg_Tools
Web APP Tools for Fogg behavior collection and Focus Map. Help you find your golden behaviors that lead to your dream.


Develop under .Next and you can deploy on Vercel as well.

Local:
```bash
npm install
npm run dev
```

Browser:
http://localhost:3000
