# Fogg Tools 待办事项

## 总览

这个文件只记录尚未进入当前实现周期的待办事项。当前最重要的待办主题是 **AI 统一接入**：它会影响黄金行为探索器、能力链设计器、锚点提示设计器和 HTML 分析报告，因此不应该在某一个页面里临时实现。

当前结论：

- 短期不接真实 AI API，避免拖慢第三工具当前闭环。
- 先在需要的位置预留“复制给 AI 的提示词”能力。
- 等三个工具的核心流程、缓存、报告和移动端体验稳定后，再统一设计 AI 设置和 API 调用层。

优先级：

- `P0`：先完成手动流程，不依赖 AI。
- `P1`：加入“复制给 AI 的提示词”，帮助用户手动借助外部 AI。
- `P2`：统一 AI 设置、serverless API route 和模型供应商适配。

### 3. 各工具的 AI 任务

#### 3.1 锚点提示设计器

##### 珍珠习惯：把有益习惯设计成微习惯

输入：

- 烦恼事件
- 用户选择的有益习惯
- 用户偏好的方法：规模缩小化 / 入门步骤化 / 混合

输出：

- 5 个微习惯候选
- 每个候选标明使用的方法
- 每个候选尽量小到可以立刻执行

示例提示词：

```text
请把“放松肩颈”设计成 5 个足够小、可以在“邻居装修噪音”之后立刻执行的微习惯。

请分别使用两种思路：
1. 规模缩小化：把完整习惯缩小到更小版本。
2. 入门步骤化：只设计进入这个习惯的第一步。

要求：
- 每个候选必须非常小，最好 30 秒内可以完成。
- 每个候选必须具体可执行。
- 不要写成泛泛建议。
- 输出 JSON 数组，每项包含 method、text、reason。
```

##### 普通微习惯配方：生成候选微行为

输入：

- 可靠锚点
- 用户想培养的新习惯方向

输出：

- 3 到 5 个足够小的新微行为候选

#### 3.2 能力链设计器

##### 突破想法生成

输入：

- 困难习惯
- 薄弱环节：时间 / 资金 / 体力 / 脑力 / 日程

输出：

- 每个薄弱环节 3 到 5 个突破想法
- 标明对应角度：提升技能 / 获取工具和资源 / 规模缩小化 / 入门步骤化

#### 3.3 黄金行为探索器

##### 候选行为发散

输入：

- 用户愿望

输出：

- 多个具体行为候选
- 每个候选尽量具体、可观察、可执行

#### 3.4 HTML 分析报告

##### 报告摘要生成

输入：

- 黄金行为结果
- 能力链结果
- 锚点提示配方

输出：

- 一段正式但不夸张的分析摘要
- 适合放入 HTML 报告开头

### 4. 安全与隐私

目标：AI 能力上线时不让 API key 和用户输入变成隐患。

待办：

- [ ] 明确 API key 存储策略：Vercel 环境变量优先，用户自带 key 作为高级选项。
- [ ] 首页或设置页加入 API key 风险说明。
- [ ] 避免在 localStorage 中默认保存敏感 key；如保存，必须由用户主动选择。
- [ ] serverless route 不记录用户输入和 key。
- [ ] 错误提示不回显完整 key。
- [ ] 报告导出时不包含 API key 或模型调用日志。

### 5. 暂缓原因

AI 接入暂缓，不是因为不可行，而是因为它属于跨工具箱基础设施。

当前优先级仍然是：

1. 完成锚点提示设计器的手动流程。
2. 稳定三个工具的统一导航、缓存、报告和移动端体验。
3. 再统一设计 AI 能力，避免每个工具各自接一套。
