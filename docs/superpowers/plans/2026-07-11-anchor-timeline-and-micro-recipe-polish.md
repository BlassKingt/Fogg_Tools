# 时间轴拖动柄与微习惯配方出口优化计划

## 目标

对 `/anchor-prompts` 的两个局部交互做克制优化，不改变既有数据结构和主流程：

1. 时间轴中的拖动柄更细长，并与右侧习惯输入框组成一个连续控件。
2. 微习惯配方页更明确地强调“建议完成 3 张”，同时为暂时想不出第 3 张的用户提供可控的提前继续出口。

## 交互决定

### 时间轴拖动柄

- 将当前独立的宽按钮改为窄竖向抓手。
- 抓手和输入框共享同一行并贴合，左侧抓手使用左圆角，输入框使用右圆角。
- 保留 pointer 拖动逻辑、键盘可聚焦状态和移动端触控能力。
- 移动端不再让抓手跨越输入框与操作按钮两行，避免视觉过重。

### 微习惯配方目标与提前继续

- 在页面说明上方增加配方目标提示，用大号数字 `3` 强化推荐数量，并显示当前完成进度。
- 原“下一步：创建珍珠习惯”仍需至少 3 张配方才可用。
- 当已有 1–2 张配方时，显示次级按钮“想不出了，先这样吧”，允许继续到珍珠习惯。
- 0 张配方时不提供提前继续；达到 3 张后隐藏该次级出口，避免与主按钮重复。

## 验收标准

- 桌面端拖动柄与输入框贴合，无双重圆角或明显断缝，拖动排序仍可用。
- 375px 移动端输入、拖动和锚点/删除操作均可见，无页面级横向溢出。
- 微习惯配方页大号 `3` 清晰但不压过页面标题，并能显示 `0/3`、`1/3` 等进度。
- 0 张配方不能进入下一步；1–2 张可通过次级出口继续；3 张后主按钮可用。
- `npm run build` 和 `git diff --check` 通过。
