# 公开首版先保持 Client-Only

第一个公开 Vercel 版本先保持 client-only，不引入后端、账号系统或数据库。两个现有工具本质上都是浏览器内的本地工作流，因此 client-only 发布可以降低隐私风险、简化部署，同时为之后加入 localStorage、导出或分享链接留下空间。

**状态**：accepted

**考虑过的方案**：
- 现在就加入后端和持久化存储。
- 首个整合版本只把状态保存在浏览器内存中。
- 立刻把 localStorage 作为产品需求加入。

**影响**：
- 首版不应把用户输入的敏感内容发送到服务器。
- 进度保存和分享能力是后续功能，不是首次部署的 blocker。
