# 保持独立工具，并提供推荐连续流程

公开产品会让两个工具都可以独立使用，同时推荐从黄金行为探索器进入突破设计的连续流程。这样既保留了“用户带着困难习惯直接进入”的独立价值，也让产品主线能从愿望一路走到黄金行为，再走到更容易执行的方法。

**状态**：accepted

**考虑过的方案**：
- 只把两个工具作为彼此独立的入口。
- 强制每个用户走完一个很长的线性流程。
- 保留独立入口，并添加从工具一到工具二的推荐连接。

**影响**：
- 工具箱首页需要清楚呈现两个使用场景。
- 黄金行为探索器的结果页应为黄金行为提供“继续到突破设计”的入口。
- 能力链设计器需要同时支持直接进入，以及从黄金行为预填进入。
