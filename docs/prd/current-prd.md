# 当前 PRD：Fogg Tools 公开整合版

## 目标

把现有的黄金行为探索器和能力链设计器整合成一个公开可访问、可部署到 Vercel 的 web 产品。

## 用户

对行为设计、习惯养成、降低行动难度感兴趣的公开用户。

## 产品形态

产品是一个工具箱：包含两个可独立使用的工具，同时提供一条推荐的连续流程：

1. 在黄金行为探索器里从愿望开始。
2. 生成候选行为。
3. 按影响度和容易度排序。
4. 找到黄金行为。
5. 把选中的黄金行为继续带入突破设计。

如果用户已经知道一个难以坚持的习惯，可以直接进入能力链设计器。

## 首版范围

- `/`：功能性的工具箱首页。
- `/golden-behavior`：黄金行为探索器页面。
- `/ability-chain`：能力链设计器页面。
- 可在 Vercel 上公开部署的 build。
- 统一的产品语言、导航和视觉框架。
- 从黄金行为结果进入突破设计的连接。
- 首版只使用 client-only 状态。

## 首版不做

- 账号或登录。
- 服务端持久化。
- 数据库存储。
- 多人协作。
- Analytics。
- 分享链接。
- 超出必要共享布局之外的完整 design system 抽取。

## 用户场景

**场景 1：用户有愿望，但不知道先做什么**

用户选择黄金行为探索器，输入愿望，收集候选行为，排序后找到黄金行为，然后把其中一个继续带入突破设计。

**场景 2：用户知道哪个行为很难坚持**

用户选择能力链设计器，输入困难习惯，标记薄弱环节，生成突破想法，最多选择三个方案，并在突破设计中继续评估。

**场景 3：用户从黄金行为进入**

用户在黄金行为结果页点击“继续到突破设计”。能力链设计器打开后带入该行为，用户不需要重新输入上下文。

## 成功标准

- `npm run build` 成功。
- `/`、`/golden-behavior`、`/ability-chain` 本地可访问。
- 黄金行为探索器仍能完成原有流程。
- 能力链设计器仍能完成原有流程。
- 一个黄金行为可以被传入能力链设计器。
- UI 在桌面端连贯，在移动端可用。
